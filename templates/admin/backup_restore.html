Security Notice: Controlled Disaster Restoration
Backup restoration is an air-gapped administrative operation. You can verify archive integrity and download snapshots here for automated or offline restoration.
Safety Guidelines
  • Always run checksum verification prior to staging restoration
  • Capture an active live snapshot before replacing system files
  • Ensure concurrent user file uploads are paused during recovery
  • Verify database schema versions match current runtime core
Restoration Procedure
  1. Download and inspect the validated ZIP backup archive
  2. Verify SHA-256 hash against system checksum record
  3. Extract SQLite database to instance/safevault.db
  4. Mount user ciphertext chunks to the files/ directory
